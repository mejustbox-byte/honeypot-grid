# Installation

Разворачивайте ханипоты только в отдельной лабораторной сети. Запретите маршрутизацию к production, ограничьте исходящие соединения, включите централизованный журнал и настройте автоматическое уничтожение экземпляров.

До появления автоматизированного менеджера не подключайте реальные внешние сервисы и не используйте реальные credentials.
