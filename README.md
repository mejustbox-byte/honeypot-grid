# Honeypot Grid

Фреймворк управления изолированными ханипотами и сбора threat intelligence.

## Основные компоненты

- менеджер жизненного цикла;
- образы сервисов-приманок;
- сбор и нормализация событий;
- безопасный анализ загруженных файлов;
- экспорт обезличенных IoC.

Каждый ханипот должен находиться в отдельном сегменте с запретом pivoting и контролем egress. Публикация данных допускается только после удаления персональных данных и адресов инфраструктуры.
